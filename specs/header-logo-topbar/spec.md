# SPEC-088 — Логотип в верхней панели, контакты рядом с языком

**Status:** implemented
**Owner:** Zhuravlev Artem
**Last updated:** 2026-10-28

## Problem

Логотип стоит в основной строке шапки, а выпадающее меню «Контакты» — слева в верхней панели,
далеко от переключателя языка. Слово «Контакти» не даёт клиенту ничего, пока он не откроет меню.

## Purpose

Верхняя панель: слева логотип, справа — информационное меню, затем (с отступом) блок
«контакты + язык». Вместо слова «Контакты» в кнопке выводится первый номер телефона.

## Scope

- `custom/theme/ocs/template/common/header.twig`: логотип переезжает из `.ocs-head` в `#top`; кнопка контактов — первый телефон; контакты перед `{{ language }}`.
- CSS темы: раскладка `#top.ocs-util`, сетка `.ocs-head-grid` без логотипа, отступ между блоком меню и блоком «контакты + язык».
- Пакет темы (`npm run pack:theme`), `custom/VERSION`, тест темы.

## Out of scope

- Содержимое выпадающего меню контактов, настройки телефонов, `core/`.
- Мобильная шапка (SPEC-059): логотип на телефоне остаётся как сейчас (верхняя панель там скрыта).

## Functional requirements

- **REQ-HLT-001** — На десктопе/планшете (≥768px) логотип выводится в `#top` слева, в той же разметке (ссылка/без ссылки на главной, `<h1>` при отсутствии картинки); в `.ocs-head` его нет.
- **REQ-HLT-002** — На телефоне (<768px) логотип по-прежнему показывается над поиском: либо ровно один логотип в DOM, перемещаемый CSS-сеткой, либо второй экземпляр скрыт; дублей в видимой области и в a11y-дереве нет.
- **REQ-HLT-003** — В `#top.ocs-util` порядок: логотип · (растяжка) · блог/акции/«Информация» · отступ ≥ `--sp-6` · контакты · язык · валюта.
- **REQ-HLT-004** — Кнопка выпадающего меню контактов показывает первый телефон из `ocs_shell.phones` (`phone.text`) вместо слова «Контакты» + шеврон; `aria-label` — переведённое «Контакты». Если телефонов нет, а другие контакты есть — остаётся слово «Контакты».
- **REQ-HLT-005** — Меню контактов открывается под кнопкой и не уходит за правый край экрана (выравнивание вправо при расположении у края).
- **REQ-HLT-006** — Основная строка шапки: каталог · поиск · действия, без пустой колонки под логотип; поиск растягивается на освободившееся место.
- **REQ-HLT-007** — Высота верхней панели с логотипом не вызывает CLS (фиксированная высота картинки), логотип ≤ 2.5rem, панель не выше ~3.25rem.

## Non-functional requirements

- **REQ-HLT-010** — Ничего не правится в `core/`; только шаблон и CSS темы.
- **REQ-HLT-011** — Текст телефона выводится как раньше (из `ocs_shell`, уже экранирован); доп. запросов к БД нет.
- **REQ-HLT-012** — Фокус-стили и клавиатурная доступность меню контактов не ухудшаются; `rtl` не ломается (логические свойства).

## Data requirements

Нет изменений данных и миграций.

## Interfaces

Storefront: `common/header` (шаблон темы). Новых маршрутов, событий и настроек нет.

## Edge cases

- Нет логотипа в настройках → `<h1><a>` с названием магазина в верхней панели.
- Нет телефонов, есть мессенджеры/адрес → слово «Контакты».
- Длинный телефон/узкий планшет (768–991px) → панель не переносится в две строки; при нехватке места скрывается блок `.ocs-strip`, а не логотип.
- Нет `ocs_top` (меню «Информация» отсутствует) → блок контактов и язык просто остаются справа.
- Верхняя анонс-строка (`ocs-announce`) остаётся над `#top`.
