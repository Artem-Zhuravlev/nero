# SPEC-081 — Latest Reviews Module

**Status:** implemented
**Owner:** Zhuravlev Artem
**Last updated:** 2026-10-28

## Problem

Отзывы о товарах видны только на странице самого товара. Нет блока «Последние отзывы»,
который можно поставить на главную, в категорию, в футер-зону и т.д. через
Дизайн → Макеты. Это социальное доказательство, которое магазин сейчас не использует.

## Purpose

Модуль `ocs_latest_reviews`: блок последних одобренных отзывов, выводимый в любую позицию
макета (content_top / content_bottom / column_left / column_right) стандартным механизмом
модулей OpenCart (Дизайн → Макеты → добавить модуль).

## Scope

- Модуль-расширение в `custom/extensions/ocs_latest_reviews/` (admin + catalog, uk-ua/ru-ru/en-gb).
- Несколько экземпляров модуля с независимыми настройками (как у `ocs_product_carousel`).
- Миграция регистрации расширения и прав.
- Включение в пакет темы (`npm run pack:theme`) и демо-данные.

## Out of scope

- Форма добавления отзыва (остаётся на странице товара).
- Модерация отзывов (core `catalog/review`).
- Ответы магазина на отзывы, фото в отзывах.
- Новые таблицы БД.

## Functional requirements

- **REQ-LRV-001** — Модуль появляется в Расширения → Модули и в Дизайн → Макеты как «OCS: Последние отзывы»; экземпляр добавляется в любую позицию любого макета.
- **REQ-LRV-002** — Настройки экземпляра: название (на каждый язык, необязательно), статус, количество отзывов (1–20, по умолчанию 6), максимальная длина текста (по умолчанию 200 символов), фильтр «только от рейтинга N и выше» (1–5, по умолчанию 1), режим «только текущий товар / категория» отключён по умолчанию (флаг «ограничить текущей категорией» на страницах категории).
- **REQ-LRV-003** — Выводятся только отзывы со `status = 1` по товарам с `status = 1`, `date_available <= NOW()`, привязанным к текущему магазину (`product_to_store`) и имеющим описание на текущем языке; сортировка `date_added DESC`.
- **REQ-LRV-004** — Карточка отзыва: автор, дата, звёзды рейтинга (SVG-звёзды из SPEC-042), обрезанный текст, миниатюра и название товара со ссылкой на товар (SEO-URL).
- **REQ-LRV-005** — Если подходящих отзывов нет, модуль не выводит ничего (пустая строка, без пустого заголовка).
- **REQ-LRV-006** — Отображение: сетка/карусель Swiper (SPEC-037) на широком экране, одна колонка в column_left/right; в стиле темы (SPEC-067), адаптивно, 2 колонки на телефоне не требуются — горизонтальный свайп.
- **REQ-LRV-007** — Опциональная разметка schema.org `Review` не выводится (не дублировать JSON-LD страницы товара, SPEC-080).

## Non-functional requirements

- **REQ-LRV-010** — Один запрос к БД на экземпляр (JOIN review/product/product_description/product_to_store, LIMIT), без N+1; результат кэшируется на 5 минут ключом (store, language, limit, min_rating, category) и сбрасывается при событиях добавления/редактирования отзыва, если это возможно без правки core (иначе TTL достаточно).
- **REQ-LRV-011** — Весь пользовательский текст экранируется (Twig autoescape OFF — экранирование вручную через `\Ocs\OrderRequest::e`/`htmlspecialchars`).
- **REQ-LRV-012** — Ничего не правится в `core/`; только расширение + миграция.
- **REQ-LRV-013** — Строки переведены на uk-ua, ru-ru, en-gb.

## Data requirements

Новых таблиц нет. Настройки экземпляров — стандартная таблица `module` (`code = ocs_latest_reviews`),
глобальных ключей не требуется. Права: `extension/module/ocs_latest_reviews` группе 1.

## Interfaces

- Admin: `extension/module/ocs_latest_reviews` (список через marketplace/extension, форма экземпляра `&module_id=`).
- Catalog: `ControllerExtensionModuleOcsLatestReviews::index(array $setting)`; модель `extension/ocs_latest_reviews/reviews` с методом `latest($limit, $min_rating, $category_id)`.
- Шаблон: `catalog/view/theme/default/template/extension/module/ocs_latest_reviews.twig`.

## Edge cases

- Товар скрыт/удалён → его отзывы не выводятся.
- Отзыв без текста → карточка показывает только рейтинг и автора.
- Длинный текст/слова без пробелов → `utf8_substr` + CSS `overflow-wrap:anywhere`.
- Нет изображения товара → placeholder.
- Мультиязычность: название товара на языке пользователя; отзыв выводится как написан.
- Экземпляр отключён или `limit` вне диапазона → значение приводится к границам.

## Acceptance criteria

- [ ] В Дизайн → Макеты модуль выбирается и ставится в content_top главной.
- [ ] На главной виден блок с N последними одобренными отзывами; неодобренные и по скрытым товарам не выводятся.
- [ ] Два экземпляра с разными настройками работают независимо.
- [ ] При отсутствии отзывов блок не рендерится.
- [ ] `npm run verify` зелёный; архив темы пересобран.
