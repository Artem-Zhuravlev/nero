# SPEC-117 — Страница корзины: степпер количества и аккуратнее вид

**Status:** implemented
**Owner:** Zhuravlev Artem
**Last updated:** 2026-10-29
**Refines:** SPEC-006 (theme), SPEC-011 (orders/checkout)

## Problem

На `checkout/cart` у поля количества стоит кнопка «Оновити» (иконка перезагрузки): число нужно менять руками и жать кнопку. Строки выглядят плоско.

## Scope

`custom/theme/ocs/template/checkout/cart.twig`, `custom/theme/ocs/stylesheet/stylesheet.css`, `custom/theme/ocs/javascript/theme.js`.

## Out of scope

Мини-корзина (модалка, SPEC-026), серверная логика `checkout/cart/edit`, блоки купона/доставки/бонусов, оформление заказа.

## Requirements

- **REQ-CART-010** — Кнопка «Оновити» (иконка `i-return`) убрана; у количества кнопки `−` и `+` вокруг поля, рядом кнопка удаления.
- **REQ-CART-011** — Нажатие `−`/`+` или изменение значения вручную отправляет форму (`checkout/cart/edit`) с задержкой ≈600 мс; количество не опускается ниже 1 (`−` неактивна на 1); подарочные сертификаты без степпера.
- **REQ-CART-012** — Степпер — единая «таблетка» с рамкой; строки корзины карточнее: скруглённая плашка с фоном и тенью при наведении, цена за строку крупнее, мобильная раскладка сохранена.
- **REQ-CART-013** — Ядро не тронуто; архив темы пересобран.

## Acceptance criteria

- [x] На странице нет кнопки перезагрузки; `−`/`+` меняют количество и обновляют корзину.
- [x] `npm run verify` зелёный; `npm run pack:theme` выполнен.
