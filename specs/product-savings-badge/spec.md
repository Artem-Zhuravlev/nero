# SPEC-091 — Бейдж «Экономия» в карточке товара

**Status:** implemented
**Owner:** Zhuravlev Artem
**Last updated:** 2026-10-28

## Problem

В блоке цены карточки товара видна старая цена (зачёркнута) и новая, но покупатель должен сам считать,
сколько он экономит. Бейдж с суммой выгоды усиливает эффект скидки.

## Purpose

Если у товара действует скидочная цена, рядом с ценой показывается бейдж «Экономия: N грн» — разница между
обычной и акционной ценой в валюте, выбранной покупателем.

## Scope

- Бейдж в `.ocs-price-box` страницы товара (`product.twig` темы), рядом с новой ценой.
- Сумма считается на сервере событием `ocs`; строки uk-ua / ru-ru / en-gb; стили темы; пакет темы.

## Out of scope

- Бейдж в карточках каталога, модулях, быстром просмотре, корзине, липкой/боковой панели.
- Процент скидки, скидки по количеству (`product_discount`), изменение цены от опций.

## Functional requirements

- **REQ-SAV-001** — Бейдж выводится на странице товара только при действующей скидке (`special`) и видимой покупателю цене.
- **REQ-SAV-002** — Сумма = обычная цена − акционная, обе с налогом так же, как их показывает страница, в текущей валюте посетителя, форматируется настройками валюты магазина (символ, разделители, знаки).
- **REQ-SAV-003** — Подпись «Экономия» (uk «Ви економите», ru «Вы экономите», en «You save») + сумма; без знака минус, не копируем чужой дизайн: мягкий акцентный бейдж темы.
- **REQ-SAV-004** — Если разница ≤ 0 (после округления/налога) — бейдж не выводится; без скидки разметки нет.
- **REQ-SAV-005** — Смена опций не влияет на бейдж (относится к цене товара).

## Non-functional requirements

- **REQ-SAV-010** — Ничего не правится в `core/`; событие `ocs`, шаблон и стили темы.
- **REQ-SAV-011** — Без лишних запросов: используется уже загруженная модель товара (кэш запроса не нужен, один `getProduct`), без CLS (серверный рендер).
- **REQ-SAV-012** — Строки на uk-ua, ru-ru, en-gb; вид на телефоне без переноса, контраст текста ≥ 4.5:1.

## Data requirements

Новых таблиц/настроек нет, миграция не нужна.

## Interfaces

- Событие `catalog/view/product/product/before`: добавляет `ocs_savings` (отформатированная строка или пусто).
- Шаблон: `custom/theme/ocs/template/product/product.twig`; стили: `custom/theme/ocs/stylesheet/stylesheet.css`.
- Язык: `extension/ocs/top` (`text_savings`).

## Edge cases

- Валюта не по умолчанию -> разница считается в ней (форматирование ядра `currency->format`).
- Налог включён в цену -> разница считается от цен с налогом, как на странице.
- Цена скрыта для гостя (`config_customer_price`) -> бейджа нет.

## Acceptance criteria

- [ ] Товар 100 грн со скидкой 80 грн показывает «Ви економите: 20 грн» рядом с ценой.
- [ ] Без скидки / с истёкшей акцией бейджа нет; при смене валюты сумма в ней.
- [ ] Десктоп и телефон проверены; `npm run verify` зелёный; архив темы пересобран.
