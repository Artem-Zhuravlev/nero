# SPEC-101 — Карточка товара: степпер количества (− / +)

**Status:** implemented
**Owner:** Zhuravlev Artem
**Last updated:** 2026-10-30
**Refines:** SPEC-006 (тема), SPEC-098 (боковая карточка товара)

## Problem

Поле «Кількість» на странице товара — растянутое текстовое поле без кнопок. Можно ввести 0, больше остатка на складе и число, не кратное минимальному количеству товара.

## Scope

Шаблон `product/product.twig`, CSS и JS темы `ocs`, передача лимитов в шаблон событием `ocs` для `product/product`.

## Out of scope

Количество в корзине, быстром просмотре и карточках списков; остатки по значениям опций.

## Requirements

- **REQ-QTY-001** — Поле количества на странице товара — компактный степпер в стиле сайта: кнопки «−» и «+» по бокам от числового поля фиксированной ширины (не на всю ширину колонки).
- **REQ-QTY-002** — Шаг изменения равен минимальному количеству товара (`minimum` из админки); начальное значение — `minimum`.
- **REQ-QTY-003** — Количество не может быть меньше `minimum` (и, значит, не меньше 1): «−» блокируется на минимуме, ручной ввод приводится к допустимому значению.
- **REQ-QTY-004** — Если остаток ограничивает покупку (у товара включено «вычитать со склада» и в настройках не разрешено оформление без остатка), количество не превышает наибольшее кратное `minimum`, не выше остатка; «+» блокируется на максимуме, ручной ввод ограничивается им.
- **REQ-QTY-005** — Ручной ввод округляется до ближайшего допустимого кратного `minimum` (вниз) при потере фокуса; нечисловое значение заменяется на `minimum`.
- **REQ-QTY-006** — Без JS поле остаётся обычным полем ввода (прогрессивное улучшение); кнопки имеют `aria-label`, поле — `inputmode="numeric"`.
- **REQ-QTY-007** — Цена на странице товара (основная, старая, экономия, «без налога», плашка и боковая карточка) пересчитывается при смене количества и выбранных опций: количество × (цена по скидке/акции + надбавки опций), как считает корзина. Данные для расчёта отдаёт событие `ocs` (`pricing()`); при ошибке остаётся серверная цена.
- **REQ-QTY-008** — Кнопки «−»/«+» работают: `theme.js` грузится в `<head>`, поэтому степпер инициализируется после `DOMContentLoaded`. Подпись «Кількість» убрана, между степпером и кнопкой «Купити» есть отступ.
