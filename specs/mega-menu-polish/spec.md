# SPEC-103 — Главное меню: без «Показать все», выровненная стрелка, ровные отступы

**Status:** implemented
**Owner:** Zhuravlev Artem
**Last updated:** 2026-10-28
**Refines:** SPEC-027 (мега-меню)

## Problem

В выпадающей панели мега-меню есть ссылка «Показать все <категория>», стрелка у родительского пункта смещена вверх от центра строки, дочерние пункты слипаются и выделены жирным.

## Scope

Шаблон `ocs_mega_menu.twig` и CSS мега-меню в теме `ocs`.

## Out of scope

Жирность и красная точка у популярных родительских пунктов, мобильная раскладка.

## Requirements

- **REQ-MMP-001** — В панели мега-меню нет ссылки `.see-all`.
- **REQ-MMP-002** — Стрелка `.ocs-mega-expand` центрируется по вертикали относительно строки родительского пункта.
- **REQ-MMP-003** — Дочерние пункты и заголовок «Бренды» имеют равномерные отступы и обычную (не жирную) насыщенность.

## Acceptance criteria

- [x] `npm run verify` зелёный; архив темы пересобран.

- **TEST-MMP-001 — verifies REQ-MMP-001, REQ-MMP-002, REQ-MMP-003** — `scripts/test/mega-menu-polish.test.mjs`.
