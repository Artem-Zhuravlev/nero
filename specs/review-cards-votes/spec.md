# SPEC-127 — Карточки отзывов и «полезно / не полезно»

**Status:** draft
**Owner:** Zhuravlev Artem
**Last updated:** 2026-10-30
**Refines:** SPEC-049 (отзывы: плюсы/минусы), SPEC-116 (ответ магазина), SPEC-006 (тема)

## Problem

Отзывы на странице товара выводятся таблицей Bootstrap (полосатая `table`, автор и дата в серых ячейках, звёзды внизу) — выглядит устаревшим. Оценить полезность отзыва нельзя: лайков/дизлайков в проекте нет (проверено: в product-отзывах, `ocs_review_extra` и спеках их нет; есть только в блоге).

## Purpose

Современная карточка отзыва и аккуратные кнопки «полезно» / «не полезно» со счётчиками.

## Scope

- `product/review.twig` + стили: карточка (аватар-инициал, автор, дата, звёзды сверху, текст, плюсы/минусы, ответ магазина, кнопки оценки).
- Голосование: таблица, эндпоинт, JS, защита от накрутки.

## Out of scope

- Сортировка отзывов по полезности, жалобы на отзыв, голосование в блоге, блок «Останні відгуки» на главной.
- Админ-экран просмотра голосов.

## Functional requirements

- **REQ-REV-201** — Отзыв выводится карточкой (без `<table>`): круглый инициал автора, имя (Medium), дата справа/под именем, звёзды под шапкой, затем текст, плюсы/минусы, ответ магазина. Вид одинаков на десктопе и мобильном.
- **REQ-REV-202** — Под отзывом две кнопки-иконки (большой палец вверх/вниз, контурные) со счётчиками; поставленный голос подсвечивается, повторный клик снимает его, клик по противоположной — переключает.
- **REQ-REV-203** — Голос = одна запись на (отзыв, голосующий). Голосующий — клиент по `customer_id`, гость — по случайному cookie `ocs_rv_voter` (httponly, 1 год). Свой отзыв оценивать нельзя только если автор — тот же вошедший клиент.
- **REQ-REV-204** — Эндпоинт `POST index.php?route=extension/ocs_product_extras/review_vote` принимает `review_id`, `vote` (`up|down|none`), отдаёт JSON `{up, down, mine}`; только для одобренных отзывов (`status=1`), иначе 404-ответ JSON. Ограничение частоты: не более 30 голосов в минуту на голосующего.
- **REQ-REV-205** — Счётчики приходят вместе со списком отзывов (один запрос `GROUP BY` на страницу списка, без N+1) и работают без JS как «только чтение» (кнопки `ocs-js-only` для действия).

## Non-functional requirements

- **REQ-REV-210** — Миграция идемпотентна: `ocs_review_vote(review_id, voter, vote TINYINT, date_added)`, PK `(review_id, voter)`, индекс по `review_id`. Откат: таблица сохраняется.
- **REQ-REV-211** — Текст отзыва/автор экранируются на выводе (autoescape в Twig выключен). Подписи кнопок — в языковых файлах uk-ua / ru-ru / en-gb.
- **REQ-REV-212** — Доступность: кнопки `aria-pressed`, `aria-label` с текстом и счётчиком; фокус-стили темы.

## Data requirements

Таблица `ocs_review_vote` (см. REQ-REV-210); cookie `ocs_rv_voter`.

## Interfaces

- Шаблон `custom/theme/ocs/template/product/review.twig`, стили темы, `theme.js`.
- Контроллер в расширении `ocs_product_extras` (событие уже подмешивает данные к отзывам).

## Edge cases

- Гость без cookie -> cookie выдаётся при первом голосе.
- Неодобренный/удалённый отзыв -> ответ с ошибкой, UI откатывает кнопку.
- Дубли запросов -> идемпотентно (REPLACE/DELETE по PK).

## Acceptance criteria

- [ ] Отзывы выглядят карточками, без таблицы, звёзды сверху.
- [ ] Лайк/дизлайк ставится, снимается, переключается; счётчики сохраняются после перезагрузки.
- [ ] Повторный голос с того же браузера не увеличивает счётчик.
- [ ] `npm run verify` и `npm run pack:theme` проходят.
