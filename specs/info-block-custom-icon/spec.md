# SPEC-125 — Своя иконка для информационных блоков карточки товара

**Status:** implemented
**Owner:** Zhuravlev Artem
**Last updated:** 2026-10-30
**Refines:** SPEC-048 (информационные блоки карточки), SPEC-006 (тема)

## Problem

В Расширения → Темы → OCS → «Інформаційні блоки сторінки товару» иконку можно выбрать только из 8 зашитых в тему (truck, return, card, shield, gift, clock, phone, info). Свою иконку (например, логотип службы доставки) добавить нельзя.

## Purpose

Для каждого блока можно выбрать изображение в стандартном менеджере изображений; оно выводится вместо встроенной иконки.

## Scope

- Админка: в строке блока рядом с выпадающим списком иконок — выбор изображения через менеджер изображений (миниатюра, кнопка очистки).
- `Ocs\InfoBlocks::sanitize/view` и карточка товара (`product.twig`).

## Out of scope

- Своя иконка в «Контактных ссылках» и других редакторах.
- Автоперекраска изображения в цвет темы (картинка выводится как есть).
- Загрузка файлов в обход менеджера изображений.

## Functional requirements

- **REQ-INF-101** — В строке блока есть поле «Своя иконка»: миниатюра + выбор из менеджера изображений (`a-image`/`filemanager`, как в других формах) + кнопка «убрать». Значение — путь внутри `image/` (`catalog/...`).
- **REQ-INF-102** — Если путь задан, на витрине выводится `<img>` (с `alt=""`, фиксированный размер как у встроенных иконок) вместо SVG-символа; если пуст — прежнее поведение (иконка из списка). Существующие строки без поля работают без миграции.
- **REQ-INF-103** — Путь сохраняется только если он безопасен: без `..`, внутри каталога изображений, расширение из белого списка (`png, jpg, jpeg, gif, webp, svg`), иначе поле сбрасывается и в админке показывается ошибка в стиле SPEC-ocs «строка не пропадает молча». Значение экранируется при выводе (autoescape в Twig выключен).
- **REQ-INF-104** — Строка допустима, если задана либо иконка из списка, либо своя картинка (раньше требовалась иконка из списка; выпадающий список остаётся как запасной вариант).

## Non-functional requirements

- **REQ-INF-110** — Файл по пути не обязан существовать при сохранении; если его нет на витрине, строка выводится со встроенной иконкой (без битой картинки).
- **REQ-INF-111** — Без новых таблиц и ключей настроек: поле `image` внутри существующего `theme_ocs_info_blocks`.

## Data requirements

`theme_ocs_info_blocks` (JSON): элемент `{icon, image?, title, text, url, sort}`; `image` — строка, по умолчанию отсутствует.

## Interfaces

Админка `extension/theme/ocs` (twig + контроллер + языки uk-ua/en-gb), витрина `product/product.twig`, события `events.php` (без изменений контракта).

## Edge cases

- Картинка в менеджере позже удалена -> REQ-INF-110.
- SVG с внешними ссылками/скриптами -> выводится только через `<img>` (скрипты не выполняются).
- Путь с `../` или чужим расширением -> сбрасывается, ошибка.

## Acceptance criteria

- [ ] В админке у блока можно выбрать картинку из менеджера, миниатюра обновляется, после сохранения и перезагрузки она на месте.
- [ ] На странице товара блок показывает выбранную картинку вместо SVG-иконки; без картинки — как раньше.
- [ ] `../x.png` и `a.php` не сохраняются.
- [ ] `npm run verify` и `npm run pack:theme` зелёные.
