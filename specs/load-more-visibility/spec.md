# SPEC-096 — Кнопка «Показать ещё» только при наличии пагинации

**Status:** implemented
**Owner:** Zhuravlev Artem
**Last updated:** 2026-10-28
**Refines:** SPEC-034 (listing), SPEC-095 (listing toolbar)

## Problem

В категории/производителе/поиске/скидках кнопка «Показать ещё N» видна, даже когда все товары уже на странице и пагинации нет (скриншот: категория «Mac», один товар). Причина: правило `.ocs-more button[hidden] { display: none }` лежит в слое `legacy`, а правила `.btn` в более поздних слоях его перебивают, поэтому атрибут `hidden` не скрывает кнопку.

## Scope

Шаблоны `product/category`, `manufacturer_info`, `search`, `special` и CSS кнопки.

## Out of scope

Логика подгрузки в `theme.js` (уже показывает кнопку только при наличии ссылки на следующую страницу), пагинация, тексты.

## Requirements

- **REQ-LML-001** — Если пагинации нет (все товары видны), кнопка «Показать ещё» и её обёртка не выводятся в HTML.
- **REQ-LML-002** — Кнопка с атрибутом `hidden` действительно скрыта независимо от слоёв CSS; JS скрывает её после загрузки последней страницы.
- **REQ-LML-003** — Если пагинация есть, поведение прежнее (кнопка видна до последней страницы).

## Acceptance criteria

- [x] При одной странице товаров кнопки нет на всех четырёх типах страниц; при нескольких — есть и скрывается на последней; `npm run verify` зелёный; архив темы пересобран.
