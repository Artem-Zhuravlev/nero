# SPEC-090 — Мобильная шапка в одну строку (sticky) и кастомное мобильное меню

**Status:** implemented
**Owner:** Zhuravlev Artem
**Last updated:** 2026-10-28

## Problem

На телефоне шапка занимает три строки (логотип, поиск, широкая кнопка «Каталог») и уезжает при прокрутке
(SPEC-038 делает её `static`). Мобильный каталог открывается через Bootstrap `data-toggle="collapse"`:
`.collapsing` анимирует высоту, а панель при этом полноэкранная `position: fixed` и переносится в top layer
(Popover API) уже после анимации — отсюда рывки и «дёрганье» при открытии/закрытии.

## Purpose

Одна компактная sticky-строка: **кнопка каталога · логотип · поле поиска** (как в примере заказчика).
Мобильное меню открывается собственным кодом (без Bootstrap collapse) с плавной анимацией без скачков.

## Scope

- `custom/theme/ocs/template/common/header.twig`, `common/menu.twig`,
  `custom/extensions/ocs_mega_menu/.../ocs_mega_menu.twig`: убрать `data-toggle="collapse"`/`data-target` у кнопок открытия/закрытия, добавить собственные хуки.
- `custom/theme/ocs/javascript/theme.js`: `initMega()` — собственный открыватель панели (<768px).
- `custom/theme/ocs/stylesheet/stylesheet.css`: сетка мобильной шапки, sticky, анимация панели и подпунктов.
- Пакет темы (`npm run pack:theme`), `custom/VERSION`, тест темы.

## Out of scope

- Десктопная шапка и выпадающий mega-menu ≥768px (остаются как сейчас).
- Нижний таб-бар, содержимое меню (категории, блок `.ocs-mnav-extra`), `core/`.
- Иконки действий (аккаунт/сравнение/избранное/корзина) в шапке — остаются в таб-баре (SPEC-059).

## Functional requirements

- **REQ-MHS-001** — При ширине <768px `.ocs-head-grid` — одна строка, три колонки в порядке: кнопка каталога · логотип · поиск (`"cat logo search"`, `auto auto minmax(0,1fr)`). Отдельные ряды «поиск» и «каталог» исчезают.
- **REQ-MHS-002** — Кнопка каталога на телефоне — квадратная кнопка-иконка (`i-menu`) с акцентным фоном, 2.5rem × 2.5rem; текст «Каталог» визуально скрыт, остаётся доступным (`aria-label`/sr-only).
- **REQ-MHS-003** — Логотип в строке: высота ≤2rem, `max-inline-size` ~6.5rem, не сжимается (`flex: none`); без картинки — `<h1>` уменьшенного размера с многоточием. Один логотип в видимой области.
- **REQ-MHS-004** — Поле поиска занимает всё оставшееся место, высота 2.5rem, pill-форма, стили SPEC-058 сохраняются.
- **REQ-MHS-005** — Шапка на телефоне `position: sticky; top: 0` (отмена `static` из SPEC-038), всегда видна при прокрутке; не перекрывает якоря (`scroll-padding-top`); z-index ниже полноэкранного меню и поп-апов.
- **REQ-MHS-006** — Мобильное меню (<768px) открывается без Bootstrap collapse: клик по кнопке каталога переключает состояние собственным JS; `data-toggle="collapse"` у кнопок открытия/закрытия удалён.
- **REQ-MHS-007** — Анимация открытия: панель выезжает (`transform`/`opacity`, ~250–300ms, ease-out), подложка плавно проявляется; закрытие — обратная анимация, после `transitionend` панель убирается из top layer/дерева. Анимируются только `transform` и `opacity`.
- **REQ-MHS-008** — Нет скачков: при открытии не меняется ширина/позиция страницы (блокировка прокрутки + `scrollbar-gutter`), позиция прокрутки сохраняется после закрытия; панель с `overscroll-behavior: contain`; быстрые повторные клики не ломают состояние (идемпотентный toggle, прерывание анимации).
- **REQ-MHS-009** — Раскрытие подкатегорий в панели плавное: высота через `grid-template-rows: 0fr → 1fr`, шеврон поворачивается плавно, без `display: none ↔ block`-скачка.
- **REQ-MHS-010** — Доступность: у кнопки каталога `aria-expanded`/`aria-controls` синхронизируются с состоянием; Esc и «×» закрывают панель; при открытии фокус уходит в панель, при закрытии возвращается на кнопку; закрытая панель недоступна для фокуса.
- **REQ-MHS-011** — `prefers-reduced-motion: reduce` — анимации отключены, логика та же.
- **REQ-MHS-012** — При переходе через 768px (поворот, ресайз) открытая панель сбрасывается, десктопное меню работает как прежде; `.ocs-mnav-extra` по-прежнему переносится (SPEC-059).

## Non-functional requirements

- **REQ-MHS-020** — Ничего не правится в `core/`; Bootstrap JS не меняется; только шаблоны, JS и CSS темы/расширения.
- **REQ-MHS-021** — Без новых зависимостей; CSS в существующих `@layer`; логические свойства (rtl не ломается).
- **REQ-MHS-022** — Без CLS: высота sticky-строки фиксирована (≤3.5rem), размер логотипа задан.
- **REQ-MHS-023** — Без JS страница остаётся рабочей (навигация через таб-бар и ссылки).

## Data requirements

Нет изменений данных и миграций.

## Interfaces

Storefront: `common/header`, `common/menu`, модуль `ocs_mega_menu`. Новых маршрутов, событий и настроек нет.

## Edge cases

- Нет логотипа → название магазина, обрезается многоточием.
- Экран 320px: кнопка 2.5rem + логотип (сужается до `min-inline-size: 3.5rem`) + поиск ≥ ~9rem.
- Открыта клавиатура в поиске — sticky-строка не прыгает.
- Меню открыто, пользователь переходит по ссылке/«назад» — блокировка прокрутки снимается.
- Модуль `ocs_mega_menu` отключён → `common/menu.twig` получает ту же логику кнопки.
- Браузер без Popover API → панель `position: fixed` с `--z-menu`, та же анимация.
