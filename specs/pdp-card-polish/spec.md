# SPEC-124 — Характеристики, иконки наличия, код товара в карточке, без bold

**Status:** implemented
**Owner:** Zhuravlev Artem
**Last updated:** 2026-10-30
**Refines:** SPEC-006 (тема), SPEC-044 (карточка), SPEC-113 (не в наличии)

## Problem

1. Таблица характеристик на странице товара — стандартная bootstrap-таблица с рамками (`table table-bordered`), выглядит устаревшей.
2. Наличие подписано только текстом/точкой; нет быстрого визуального признака.
3. Код товара в карточке списка лежит `position:absolute` поверх фото и конфликтует с бейджами.
4. По всему сайту много жирного текста (600–800 в ~130 правилах): названия, подписи, ссылки, кнопки; акцент размыт.

## Purpose

Современная таблица характеристик; тонкая галочка/крестик у статуса наличия; код товара обычным блоком над названием; жирность только у цен и заголовков разделов.

## Scope

- `product/product.twig` + CSS: таблица характеристик (REQ-PDP-001).
- Иконки наличия на странице товара, в карточке `ocs/card.twig`, в блоках/подсказках, где выводится `.ocs-stock` (REQ-STK-001..002).
- Переключатели «Показывать наличие» и «Показывать артикул» **уже реализованы** (`theme_ocs_show_stock`, `theme_ocs_show_sku`, Расширения → Темы → OCS; миграция 0006, `Ocs\Display::apply` убирает данные во всех списках/блоках/поиске). Новых настроек не добавляем; код и статус в списках скрываются этими же двумя переключателями (REQ-CODE-002).
- Код товара в карточке: `static`, над названием (REQ-CODE-001).
- Типографика: убрать bold (REQ-TYPO-001..003).

## Out of scope

- Админка, email, печатные формы.
- Новые поля настроек, смена шрифта (SPEC-121).
- Страница сравнения (`compare.twig`) — только наследует общие веса.

## Functional requirements

- **REQ-PDP-001** — Характеристики: без внешних рамок; строки двумя колонками (название приглушённым цветом, значение обычным), чередующийся фон строк (`--bg-alt`), скруглённый контейнер, заголовок группы — маленький uppercase приглушённый, без `<strong>`; на мобильном колонки в столбик (название над значением).
- **REQ-STK-001** — Рядом со статусом «В наличии» (и «Мало») выводится тонкая галочка (SVG, stroke 1.5–1.75, цвет `--success` / `--warning`), у «Нет в наличии» — тонкий крестик (цвет `--text-muted`). Заменяет точку `.ocs-dot` в карточке.
- **REQ-STK-002** — Иконки в одном спрайте `#i-check`, `#i-x-thin`; декоративные (`aria-hidden`), смысл несёт текст.
- **REQ-CODE-001** — В `ocs/card.twig` код (`product.model`) выводится в `.caption` перед `.ocs-card-name` блоком `position: static`; из `.image` убран; сопутствующие правила `position:absolute`/`ocs-slot-bl ~ .ocs-code` удалены.
- **REQ-CODE-002** — Код и статус наличия скрываются существующими переключателями `show_sku` / `show_stock` (данные не приходят в шаблон).
- **REQ-TYPO-001** — Базовый вес текста 400 везде: `strong, b, th, label`, названия, ссылки, меню, подписи, бейджи, теги, табы, фильтры, формы.
- **REQ-TYPO-002** — Жирность (600–800) остаётся только у: цен (`.price*`, `.ocs-price`, `.ocs-now`, суммы корзины/итогов, sticky-цена), заголовков (`h1–h6`, `.ocs-sec-title`, `.ocs-block-title`, заголовки колонок/секций).
- **REQ-TYPO-003** — Кнопки — вес 500 (medium) как исключение для читаемости; по умолчанию не bold.

## Non-functional requirements

- **REQ-NFR-001** — Изменения только в `custom/theme/ocs/**`, без правок `core/`; тема остаётся рабочей без JS.
- **REQ-NFR-002** — Контраст иконок и текста ≥ 4.5:1 (иконки ≥ 3:1).
- **REQ-NFR-003** — После изменений `npm run verify` зелёный и пересобран `dist/ocs-theme-<VERSION>.ocmod.zip`.

## Data requirements

Без новых настроек и миграций.

## Interfaces

Шаблоны `product/product.twig`, `ocs/card.twig`, спрайт иконок, `stylesheet.css`.

## Edge cases

- Нет атрибутов → секция характеристик не выводится (как сейчас).
- `show_sku = 0` → кода нет, название карточки без отступа.
- У товара нет `model` → блок не выводится.
- Атрибут с очень длинным значением → переносится, колонка названия ≤ 40%.

## Acceptance criteria

- [ ] Характеристики выглядят как лёгкая полосатая таблица без рамок, на 375px — в столбик.
- [ ] «В наличии» с тонкой галочкой, «Нет в наличии» с крестиком: страница товара, листинг, карусели.
- [ ] Код товара в карточке над названием, не перекрывает фото и бейджи.
- [ ] При выключенных «наличие» / «артикул» в настройках темы они пропадают в списках.
- [ ] `grep` по CSS: `font-weight` ≥ 600 только у цен и заголовков (+ кнопки 500).
- [ ] `npm run verify` и `npm run pack:theme` выполнены.
