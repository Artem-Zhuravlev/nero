# SPEC-107 — Мобильное меню: логотип в шапке панели, информационные страницы под details

**Status:** implemented
**Owner:** Zhuravlev Artem
**Last updated:** 2026-10-28
**Refines:** SPEC-059 (мобильная навигация), SPEC-090 (полноэкранная панель каталога)

## Problem

В мобильной панели каталога логотип стоит внизу, в блоке перенесённой верхней полосы, а пустое место сверху (слева от кнопки закрытия) не занято. Информационные страницы («Інформація») раскрыты списком и удлиняют панель.

## Scope

- `theme.js` (`initMobileNav`), `stylesheet.css`: на `<768px` логотип переносится в шапку панели; список информационных страниц оборачивается в `<details>`.

## Out of scope

Десктопная вёрстка, шаблоны PHP/Twig, ядро `core/`.

## Functional requirements

- **REQ-MML-001** — На `<768px` `#logo` находится в `.ocs-mnav-head` — первом блоке панели каталога, слева от кнопки закрытия; внизу панели логотипа нет.
- **REQ-MML-002** — На `<768px` пункты информационных страниц (`.ocs-top-drop .dropdown-menu`) лежат внутри `<details class="ocs-mnav-pages">` со `<summary>` с названием раздела; по умолчанию свёрнуто.
- **REQ-MML-003** — При переходе через 768px логотип и список страниц возвращаются на прежние места (десктоп без изменений).

## Acceptance criteria

- [x] На 375px логотип вверху панели, не перекрывает кнопку ✕.
- [x] Информационные страницы свёрнуты под `<details>`, раскрываются по клику.
- [x] Десктоп без изменений; `npm run verify` зелёный; архив темы пересобран.
