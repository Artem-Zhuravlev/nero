# SPEC-098 — Липкий блок карточки товара без производителя, наличия и кода

**Status:** implemented
**Owner:** Zhuravlev Artem
**Last updated:** 2026-10-28
**Refines:** SPEC-006 (theme)

## Problem

В липком блоке (`.ocs-side-card`) карточки товара дублируются производитель, код товара и наличие, которые уже есть в основном блоке информации о товаре.

## Scope

Шаблон `product/product.twig`, блок `<aside class="ocs-side-card">`.

## Out of scope

Основной блок информации о товаре, нижняя липкая панель покупки (`ocs-sticky-buy`).

## Requirements

- **REQ-PSC-001** — В `.ocs-side-card` не выводятся производитель, код товара (с кнопкой копирования) и наличие; остаются фото с бейджами, название, цена и кнопки действий.

- **REQ-PSC-002** — Бейджи на фото прижаты к краю карточки как текст (без доп. отступа); цена: сначала актуальная (20px), правее зачёркнутая старая на 2px меньше.

## Acceptance criteria

- [x] В боковом блоке нет производителя, кода и наличия; `npm run verify` зелёный; архив темы пересобран.
