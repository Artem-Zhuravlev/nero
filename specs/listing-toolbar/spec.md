# SPEC-095 — Панель сортировки в листингах

**Status:** implemented
**Owner:** Zhuravlev Artem
**Last updated:** 2026-10-28
**Refines:** SPEC-034 (listing), SPEC-038 (layout)

## Problem

Панель «вид / сортировка / показывать» в каталоге липкая, подписи не выровнены по центру относительно select, переключатель вида — один овал, лишний выбор лимита.

## Scope

Шаблоны `product/category`, `manufacturer_info`, `search`, `special` и CSS панели.

## Out of scope

Логика переключения вида (core `common.js`, id `list-view`/`grid-view` сохраняются), пагинация, «показать ещё».

## Requirements

- **REQ-LTB-001** — Панель не липкая (обычный поток страницы).
- **REQ-LTB-002** — Порядок: слева сортировка, справа переключатель вида; подпись и select выровнены по центру по вертикали.
- **REQ-LTB-003** — Переключатель вида — две отдельные круглые кнопки, не один овал.
- **REQ-LTB-004** — Выбор лимита («Показывать») удалён из панели.
- **REQ-LTB-005** — На телефоне переключатель вида скрыт, остаётся только сортировка.

## Acceptance criteria

- [x] Панель прокручивается вместе со страницей; порядок и вид соответствуют требованиям на десктопе и телефоне; `npm run verify` зелёный; архив темы пересобран.
