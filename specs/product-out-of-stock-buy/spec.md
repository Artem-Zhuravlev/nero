# SPEC-113 — Товар не в наличии: только предзаказ и «Повідомити про надходження», меньшая цена

**Status:** implemented
**Owner:** Zhuravlev Artem
**Last updated:** 2026-10-29
**Refines:** SPEC-006 (theme), SPEC-025 (pre-order / back in stock)

## Problem

У товара с остатком 0 и меньше в карточке одновременно видны кнопка «Купити», «Передзамовлення», текст «Дякуємо! Ми зв'яжемося, щойно товар надійде.» и «Повідомити про надходження». Кнопка «Купити» не должна показываться, лишний текст не нужен. Цена в карточке слишком крупная.

## Scope

`custom/theme/ocs/template/product/product.twig`, `custom/theme/ocs/stylesheet/stylesheet.css`.

## Out of scope

Логика расчёта предзаказа (`ocs_preorder`), формы запросов, карточки в листингах, боковой блок.

## Requirements

- **REQ-OOS-001** — Если для товара активен предзаказ (`ocs_preorder`), кнопка «Купити» (`#button-cart`) не выводится в разметке и не может появиться через CSS.
- **REQ-OOS-002** — Под кнопкой предзаказа не выводится пояснение (`ocs-req-note`); остаются кнопка предзаказа и кнопка «Повідомити про надходження».
- **REQ-OOS-003** — Цена в основном блоке карточки товара уменьшена с `--fs-3xl` (48px) до `--fs-2xl` (34px).

## Acceptance criteria

- [x] Товар с остатком <= 0: видны только «Передзамовлення» и «Повідомити про надходження», без «Купити» и без текста.
- [x] Цена 34px; `npm run verify` зелёный; архив темы пересобран.
