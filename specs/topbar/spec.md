# SPEC-082 — Строка над хедером (Top Bar)

**Status:** implemented
**Owner:** Zhuravlev Artem
**Last updated:** 2026-10-28

## Problem

Над шапкой нужна информационная строка (акция, доставка, промокод). Сейчас в `ocs_shell` есть
упрощённый «анонс» (SPEC-031): текст + ссылка на весь текст, даты показа, крестик. Нельзя
добавить кнопку, выбрать цвет/вид, а вариант «текст + кнопка» выглядит не так, как простой текст.

## Purpose

Модуль `ocs_topbar` (Расширения → Модули): строка над хедером с мультиязычным текстом,
необязательной ссылкой на текст и необязательной кнопкой с произвольной ссылкой. Два режима
выглядят одинаково аккуратно: только текст, либо текст + кнопка.

## Scope

- Расширение `custom/extensions/ocs_topbar/` (admin + catalog, uk-ua / ru-ru / en-gb).
- Вывод в `header.twig` темы над `<nav id="top">` на место старого анонса.
- Совместимость со старым анонсом `ocs_shell` (см. REQ-TBR-007).
- Стили в теме, пакет темы (`npm run pack:theme`), демо-данные.

## Out of scope

- Несколько строк/ротация сообщений (слайдер), таргетинг по страницам/группам клиентов.
- Иконки/картинки в строке, таймер обратного отсчёта.
- Правки `core/`.

## Functional requirements

- **REQ-TBR-001** — Модуль в Расширения → Модули как «OCS: Строка над хедером»; одна глобальная настройка (не слот макета — строка всегда над шапкой), права `extension/module/ocs_topbar` группе 1.
- **REQ-TBR-002** — Общие настройки: статус; фон (пресеты: акцент темы, тёмный, светлый, свой HEX); показывать с/по (даты, необязательно); «можно закрыть» (крестик, запоминание в cookie/localStorage по ID сообщения — как у текущего анонса).
- **REQ-TBR-003** — На каждый язык: текст (обязательно, иначе для языка строка не выводится), URL текста (необязательно — тогда текст кликабелен), подпись кнопки, URL кнопки.
- **REQ-TBR-004** — Кнопка выводится только если заданы и подпись, и URL; URL произвольный (внутренний путь, абсолютный http/https, `tel:`, `mailto:`); опасные схемы (`javascript:`, `data:`) отбрасываются. Опция «открывать в новой вкладке» для кнопки и ссылки.
- **REQ-TBR-005** — Стиль кнопки: «залитая» / «контурная», цвет подбирается автоматически под фон (контраст текст/кнопка ≥ 4.5:1 для пресетов).
- **REQ-TBR-006** — Вид: (а) только текст — по центру, одна строка, без лишней высоты; (б) текст + кнопка — текст и кнопка в одной строке по центру, кнопка компактная (pill, высота ≈ 28px), одинаковая высота строки в обоих режимах. На телефоне: текст переносится до 2 строк, кнопка остаётся рядом/под текстом по центру, крестик не перекрывает контент.
- **REQ-TBR-007** — Если `ocs_topbar` включён и есть текст для языка — выводится он, а старый анонс `ocs_shell` не выводится. Иначе поведение SPEC-031 не меняется (обратная совместимость).
- **REQ-TBR-008** — Строка не sticky, не вызывает сдвигов макета (CLS): серверный рендер, высота известна; скрытие по крестику без прыжка (как у существующего анонса).

## Non-functional requirements

- **REQ-TBR-010** — Ничего не правится в `core/`; только расширение, правка шаблона темы, миграция.
- **REQ-TBR-011** — Весь пользовательский текст экранируется при выводе (Twig autoescape OFF); URL проходят `safeUrl`.
- **REQ-TBR-012** — Без дополнительных запросов к БД: настройки читаются из `setting` (уже загружены), без N+1.
- **REQ-TBR-013** — Строки переведены на uk-ua, ru-ru, en-gb; доступность: `role="region"`, подпись, `aria-label` у крестика, фокус-стили.

## Data requirements

Глобальные настройки в `setting` (`code = module_ocs_topbar`): `module_ocs_topbar_status`,
`_bg`, `_bg_custom`, `_from`, `_to`, `_closable`, `_btn_style`, `_blank`,
`_l` (JSON: `{lang_code: {text, url, btn_label, btn_url}}`). Миграция `001_install.php`
регистрирует расширение, права, дефолты (статус 0). Новых таблиц нет.

## Interfaces

- Admin: `extension/module/ocs_topbar` (форма с вкладками языков).
- Catalog: событие `catalog/view/common/header/before` добавляет `ocs_topbar` в данные шапки; класс `system/library/ocs/topbar.php` (`Topbar::build($settings, $code, $now)` — чистая функция, как `Shell::announcement`).
- Шаблон: блок в `custom/theme/ocs/template/common/header.twig`.

## Edge cases

- Текст есть, кнопки нет → режим «только текст». Подпись без URL (или наоборот) → кнопка скрыта.
- Очень длинный текст/слово без пробелов → `overflow-wrap:anywhere`, перенос на 2 строки.
- Язык без текста → строка не выводится для этого языка.
- Даты за пределами периода → не выводится. Изменили текст → новый ID, крестик «сбрасывается».
- Свой HEX невалиден → откат на «акцент темы».

## Acceptance criteria

- [ ] Админ задаёт текст на трёх языках, ссылку на текст и кнопку; на витрине строка над шапкой.
- [ ] «Только текст» и «текст + кнопка» выглядят цельно на десктопе и на телефоне (проверено скриншотами).
- [ ] Кнопка не выводится без подписи или URL; `javascript:` отбрасывается.
- [ ] При включённом модуле старый анонс не дублируется; при выключенном — работает как раньше.
- [ ] `npm run verify` зелёный; архив темы пересобран.
