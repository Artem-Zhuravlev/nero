# SPEC-092 — Аккуратная вёрстка блока подписки

**Status:** implemented
**Owner:** Zhuravlev Artem
**Last updated:** 2026-10-28

## Problem

Блок «Знижки та новинки» на главной выглядит развалившимся: заголовок слева, текст в правой колонке на
уровне заголовка, форма отдельной строкой под ними, а под чекбоксом пустой зазор.

## Scope

Только стили темы блока `.ocs-news` (`custom/theme/ocs/stylesheet/stylesheet.css`); разметка и логика не меняются.

## Requirements

- **REQ-NEWS-001** — На широком контейнере: слева заголовок и под ним текст, справа форма (поле + кнопка в одну строку, ниже согласие); колонки выровнены по центру по вертикали.
- **REQ-NEWS-002** — На узком: всё в одну колонку; поле и кнопка одной высоты, при нехватке места кнопка переносится.
- **REQ-NEWS-003** — Чекбокс согласия компактный, в одну линию с подписью; пустой блок сообщения не занимает места.

## Acceptance criteria

- [ ] Десктоп и телефон проверены; `npm run verify` зелёный; архив темы пересобран.
