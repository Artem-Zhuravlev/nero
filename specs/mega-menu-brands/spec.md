# SPEC-104 — Бренды отдельным пунктом главного меню

**Status:** implemented
**Owner:** Zhuravlev Artem
**Last updated:** 2026-10-28
**Refines:** SPEC-027 (мега-меню), SPEC-103

## Problem

В панели каждой родительской категории мега-меню выводится блок «Бренды» с чипами брендов этой категории. Он загромождает панель и дублируется между категориями.

## Scope

Расширение `ocs_mega_menu` (контроллер, шаблон, языки, админка), модель `ocs_menu/tree`, CSS и JS мега-меню в теме `ocs`.

## Out of scope

Страница брендов (`product/manufacturer`), мобильное нижнее меню, поиск брендов в AJAX-поиске.

## Requirements

- **REQ-MMB-001** — В панели родительской категории нет блока брендов (`.ocs-mega-brands`); запрос брендов по категориям и настройка «Брендов на категорию» удаляются.
- **REQ-MMB-002** — Последним пунктом списка `.ocs-mega-l1` выводится пункт «Бренды» (иконка, ссылка на `product/manufacturer`). При наведении (или по клику при `behaviour=click`, или по стрелке на мобильном) открывается панель со всеми брендами магазина (производители со статусом магазина текущего store), отсортированными по `sort_order`, затем по имени; каждый бренд — ссылка на `product/manufacturer/info`.
- **REQ-MMB-003** — В админке мега-меню действует переключатель «Бренды в меню» (существующий ключ `module_ocs_mega_menu_brands`); при «Выключено» пункт «Бренды» не выводится вообще.
- **REQ-MMB-004** — Панель брендов использует ту же геометрию и поведение флайаута, что у категорий (без баннера и колонок категорий), на мобильном раскрывается в выдвижной панели как остальные пункты.
- **REQ-MMB-005** — Список брендов кэшируется (по store), строки на выходе экранируются так же, как остальные имена в меню.
