# SPEC-097 — Плейсхолдеры в форме быстрого заказа и кнопка закрытия без подложки

**Status:** implemented
**Owner:** Zhuravlev Artem
**Last updated:** 2026-10-28
**Refines:** SPEC-025 (request popups), SPEC-006 (theme)

## Problem

Поля формы быстрого заказа (имя, телефон, комментарий) пустые, подсказки нет. Кнопка закрытия модальных окон нарисована на сером круге, что визуально тяжело.

## Scope

Шаблон формы `ocs_request/form.twig` и CSS `.ocs-modal-close`.

## Out of scope

Тексты подписей, валидация, кнопки закрытия алертов и верхней плашки (уже без подложки).

## Requirements

- **REQ-MCP-001** — Каждое поле формы запроса (быстрый заказ, предзаказ, уведомление о наличии) имеет `placeholder` с текстом своей подписи.
- **REQ-MCP-002** — Кнопка закрытия любого модального окна (`.ocs-modal-close`) не имеет фона ни в обычном состоянии, ни при наведении; при наведении меняется только прозрачность.

## Acceptance criteria

- [x] Плейсхолдеры видны в форме; у крестика нет серого круга; `npm run verify` зелёный; архив темы пересобран.
