# SPEC-123 — Настройки Nero: вкладки, пункт меню, бренд NERO, чистка текстов

**Status:** implemented
**Owner:** Zhuravlev Artem
**Last updated:** 2026-10-29
**Refines:** SPEC-006 (тема), SPEC-047 (контакты и соцсети), SPEC-121 (шрифт)

## Problem

Форма настроек темы — одна длинная страница из `fieldset`'ов (общие, товар, schema, контакты, соцсети/мессенджеры, верхнее меню, футер, инфоблоки, изображения). Найти нужное сложно, выглядит как стандартная админка OpenCart. Страница спрятана в «Расширения → Темы». В админке везде бренд «OCS», в части текстов настроек есть разговорные слова («шмотки»).

## Purpose

Удобные настройки Nero: вкладки по логическим блокам, аккуратный вид, отдельный пункт главного меню админки, единый бренд NERO, нейтральные тексты.

## Scope

1. Форма `extension/theme/ocs`: вкладки (Bootstrap nav-tabs), активная вкладка запоминается, вкладка с ошибкой валидации открывается сама.
2. Пункт главного меню админки «Налаштування Nero» (верхний уровень, сразу под «Панель состояния»), ведёт на форму темы; событие `admin/view/common/column_left/before`, учитывает право доступа.
3. Видимые в админке названия: «OCS» → «Nero» (заголовки модулей, тема, мастер установки, подсказки, подвал формы), uk-ua / ru-ru / en-gb.
4. Нигде в поставляемом продукте (админка, шаблоны, языковые файлы, манифесты, архив темы, демо-данные) нет упоминаний Claude / Anthropic / «сгенерировано».
5. Чистка разговорных слов в подписях, подсказках и плейсхолдерах настроек модулей и темы (в т.ч. «шмотки» в синонимах суперпоиска).

## Out of scope

- Переименование кодов расширений, ключей `theme_ocs_*`, путей `extension/theme/ocs`, имён таблиц и CSS-классов `ocs-*` (ломает установленные магазины).
- `CLAUDE.md`, `docs/`, `specs/` и README репозитория (внутренние для разработки, в архив не попадают).
- Витринные тексты демо-каталога — только если найдены явно неуместные слова.

## Вкладки формы

| Вкладка | Что внутри |
| ------- | ---------- |
| Основное | директория, статус, лимиты товара, наличие/SKU, шрифт |
| Контакти | адреса, график работы, телефоны (по языкам); соцсети и мессенджеры |
| Меню | верхнее меню, страницы |
| Футер | колонки футера, логотипы оплаты |
| Блоки | инфоблоки магазина |
| SEO | schema.org (организация, логотип) |
| Зображення | размеры изображений |

## Functional requirements

- **REQ-NST-001** — Форма темы разбита на вкладки по таблице выше; все существующие `name=` сохраняются (сохранение настроек не меняется).
- **REQ-NST-002** — Контакты, график работы, телефоны, соцсети и мессенджеры — на одной вкладке «Контакти», в карточках-секциях.
- **REQ-NST-003** — Активная вкладка запоминается; при ошибке валидации открывается вкладка с ошибкой.
- **REQ-NST-004** — Аккуратный вид: карточки, подписи и подсказки, адаптив 375–1280px, без внешних зависимостей (Bootstrap 3 админки).
- **REQ-NST-005** — Пункт меню «Налаштування Nero» на верхнем уровне, иконка, ссылка на форму темы; виден только при праве `access` на `extension/theme/ocs`.
- **REQ-NST-006** — В видимых текстах админки «OCS» заменено на «Nero» во всех языках; технические идентификаторы не меняются.
- **REQ-NST-007** — В поставляемых файлах нет «Claude», «Anthropic», «generated by/with»; проверяется тестом.
- **REQ-NST-008** — В языковых файлах расширений, шаблонах настроек и словарях по умолчанию нет разговорных/нецензурных слов; «шмотки» заменено нейтральным примером («одяг=вбрання»).

## Non-functional requirements

- **REQ-NST-010** — `core/` не правится; только `custom/`.
- **REQ-NST-011** — Без новых запросов к БД на странице; JS без библиотек.
- **REQ-NST-012** — Старая ссылка «Расширения → Темы → OCS» продолжает работать.

## Edge cases

- Пользователь без права `extension/theme/ocs` — пункт меню не показывается.
- Один язык в магазине — вкладки языков в «Контакти» не ломаются.

## Acceptance criteria

- [ ] Настройки темы по вкладкам; контакты/график/соцсети/мессенджеры — на «Контакти».
- [ ] В главном меню есть «Налаштування Nero» и открывает форму.
- [ ] В админке нет видимого «OCS»; нигде нет упоминаний Claude.
- [ ] «Шмоток» и подобных слов нет.
- [ ] `npm run verify` зелёный; архив темы пересобран.
