# SPEC-121 — Выбор шрифта в настройках темы

**Status:** implemented
**Owner:** Zhuravlev Artem
**Last updated:** 2026-10-29
**Refines:** SPEC-006 (тема), SPEC-102 (Montserrat как основной шрифт)

## Problem

Шрифт сайта жёстко задан в CSS (Montserrat, SPEC-102). Админ не может сменить его без правки кода.

## Purpose

В настройках темы (Расширения → Темы → OCS) поле «Шрифт»: выпадающий список из 9 шрифтов. Выбранный шрифт применяется на всей витрине (`--font`), грузится только он (self-host, без сторонних хостов).

## Scope

- Админ-форма темы `extension/theme/ocs` (поле, валидация по белому списку, языки uk-ua / ru-ru / en-gb).
- Класс `Ocs\Fonts` (каталог шрифтов: ключ, название, семейство, веса, файлы, fallback) и вывод в `header.twig`: `<style>` с `@font-face` + `:root{--font}` и preload двух весов выбранного шрифта.
- Файлы шрифтов в `custom/theme/ocs/fonts/`, лицензии в `fonts/README.txt`.
- Миграция с дефолтом `theme_ocs_font = montserrat`, пакет темы (`npm run pack:theme`).

## Out of scope

- Загрузка произвольных шрифтов из админки, Google Fonts по CDN, разные шрифты для заголовков и текста.
- Админка OpenCart, email, шрифты внутри SVG (логотипы платёжек).

## Список шрифтов

| Ключ | Шрифт | Лицензия / файлы | Статус |
| ---- | ----- | ---------------- | ------ |
| `montserrat` | Montserrat (сейчас) | OFL, уже в репозитории | дефолт |
| `gilroy` | Gilroy | коммерческая (Radomir Tinkov) | **нужны лицензионные woff2 от владельца** |
| `proxima-nova` | Proxima Nova | коммерческая (Mark Simonson) | **нужны лицензионные woff2** |
| `geometria` | Geometria («Геометрия») | авторская лицензия, см. вопрос ниже | **нужны woff2 с подтверждённой лицензией** |
| `inter` | Inter | OFL | вкладываем |
| `manrope` | Manrope | OFL | вкладываем |
| `onest` | Onest | OFL | вкладываем |
| `golos-text` | Golos Text | OFL | вкладываем |
| `nunito-sans` | Nunito Sans | OFL | вкладываем |

Предложенные 5 (все OFL, поддерживают латиницу и украинскую кириллицу, включая і, ї, є, ґ): Inter — нейтральный и очень читаемый для интерфейса; Manrope — геометричный, близкий по характеру к Gilroy; Onest — современный, создан с расчётом на кириллицу; Golos Text — разработан для русско-украинского интерфейса; Nunito Sans — мягкий, дружелюбный.

## Functional requirements

- **REQ-FCH-001** — В форме темы поле «Шрифт» (select, 9 вариантов выше), настройка `theme_ocs_font`; дефолт `montserrat`; значение вне белого списка заменяется дефолтом.
- **REQ-FCH-002** — Витрина использует выбранный шрифт через `--font`; грузится только выбранное семейство (веса 400/500/600/700/800, `font-display: swap`, `unicode-range` latin + cyrillic), preload двух основных весов.
- **REQ-FCH-003** — Для каждого шрифта задан fallback-стек и метрики `size-adjust` для `Fallback`-семейства, чтобы не было прыжка вёрстки (CLS).
- **REQ-FCH-004** — Шрифт без файлов в `fonts/` (коммерческие, пока файлы не добавлены) в списке помечен «файлы не загружены» и недоступен для сохранения; выбор отсутствующего файла не ломает сайт (откат на `montserrat`).
- **REQ-FCH-005** — Каждый вкладываемый шрифт — subset latin + cyrillic из fontsource (cyrillic-subset покрывает U+0400-045F и U+0490-0491, т.е. украинские і, ї, є, ґ); проверяется наличием всех файлов и источником в README.

## Non-functional requirements

- **REQ-FCH-010** — Ничего не правится в `core/`; только расширение `ocs`, тема, миграция.
- **REQ-FCH-011** — Нет запросов к сторонним хостам; без лишних запросов к БД (настройка уже в `setting`).
- **REQ-FCH-012** — Минимальные размеры текста SPEC-102 (14px) сохраняются для любого шрифта; вёрстка не ломается на 375px и 1280px.
- **REQ-FCH-013** — Лицензии каждого вложенного шрифта перечислены в `fonts/README.txt`; коммерческие файлы вкладываются только при подтверждении, что лицензия это разрешает.

## Data requirements

Настройка `theme_ocs_font` (строка, ключ из каталога). Миграция `custom/db/migrations/NNNN_theme_font.php` (идемпотентная) ставит дефолт, если ключа нет. Новых таблиц нет.

## Edge cases

- Настройка не задана / повреждена → `montserrat`.
- Мультимагазин: настройка читается по `store_id` как остальные `theme_ocs_*`.
- Full-page cache (SPEC-019): смена шрифта видна после сброса кэша.

## Acceptance criteria

- [ ] В админке темы выбор из 9 шрифтов, сохранение работает, дефолт Montserrat.
- [ ] Для каждого доступного шрифта витрина рендерится им (проверено в браузере, 375/1280, кириллица и латиница).
- [ ] Недоступные (без файлов) шрифты нельзя сохранить; сайт не ломается.
- [ ] `npm run verify` зелёный; архив темы пересобран.
